=== RUN-LAB Performance Calculator ===
Stable tag: 0.1.3
Requires at least: 6.0
Tested up to: 6.8
Requires PHP: 7.4
License: Proprietary

Mounts the RUN-LAB performance calculator inside a WordPress page.

== Description ==

Add the shortcode [run_lab_calculator] to a page or post. The plugin loads the compiled calculator only when that shortcode is used.

The global site header, navigation and footer stay with the WordPress theme.

== Installation ==

1. Upload the plugin ZIP in WordPress and activate it.
2. Place [run_lab_calculator] on the page where the calculator should appear.
