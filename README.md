# RUN-LAB Performance Calculator

Standalone preview and WordPress plugin for the RUN-LAB performance calculator.

## Local preview

```bash
npm install
npm run dev
```

Open http://localhost:5173/

## Checks

```bash
npm run verify
```

That runs lint, typecheck, tests, the production build, and plugin packaging.

The installable plugin is written to `releases/run-lab-calculator.zip`. Place `[run_lab_calculator]` on a WordPress page after installing that ZIP.
